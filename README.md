# Quantitative Analysis & Behavioral Data Portfolio

## Overview
This repository contains quantitative research projects, statistical hypothesis testing frameworks, Advanced Excel/Spreadsheet modeling, and behavioral data analysis tailored for mobile game product management.

---

## Technical Competencies & Toolset

### 1. Advanced Excel & Spreadsheet Modeling
* *Cohort & Retention Analysis:* Dynamic Pivot Tables and retention tracking frameworks for player behavior.
* *Data Modeling & Lookup:* Advanced formula structures (XLOOKUP, INDEX/MATCH, nested logical conditionals).
* *KPI Dashboards:* Visualizing DAU, ARPU, LTV, and Conversion Rates with automated chart builds.

### 2. Quantitative Research Methods
* *Hypothesis Testing:* A/B test setup, significance testing, and sample size calculations.
* *Behavioral Segmentation:* Player categorization based on engagement patterns and monetization triggers.
* *Statistical Analysis:* Descriptive metrics, correlation evaluation, and variance analysis.

---

## Featured Analysis Modules
* 01_cohort_retention_model.xlsx: Interactive Excel model tracking Day-1, Day-7, and Day-30 player retention metrics.
* 02_ab_testing_framework.md: Statistical roadmap for evaluating game feature variants and conversion impact.
* 03_quantitative_research_case.pdf: Case study on quantitative data collection and behavioral pattern evaluation.
